# 🎾 Meta Tennis Tour — Профессиональный Тур 300

Интерактивный симулятор мирового теннисного тура (ATP 300), включающий 52-недельный скользящий рейтинг, Чемпионскую гонку (Live Race), полный календарь из 27 турниров (ТБШ, Мастерсы, ATP 500, Олимпиада, Итоговый турнир + фоновые ATP 250 и Челленджеры), 3D-карточки игроков в стиле Ultimate Team, радар навыков и ИИ-генерацию репортажей матчей.

🌐 **Играть онлайн в браузере (GitHub Pages):**  
👉 **[https://grig0ri4.github.io/meta-tennis-tour/](https://grig0ri4.github.io/meta-tennis-tour/)**

---

## 🏛️ Режимы работы: «Канон Автора» и Своя Вселенная

1. **🔒 Вселенная Автора (Канон) — Режим Зрителя (Read-Only):**
   - При открытии сайта гостям по умолчанию доступна каноничная вселенная автора (`Вселенная Автора (Канон)`).
   - Вы можете свободно изучать все исторические сетки турниров (включая полный архив сезона 2023), 52-недельный рейтинг ATP, Чемпионскую гонку, профили всех 300 теннисистов, Зал Славы и открывать Матч-центр (3D-карточки Ultimate Team, радар навыков, историю личных встреч H2H).
   - Любое редактирование, симуляция и сброс в Каноне Автора для гостей заблокированы.

2. **🌌 Создание собственной Вселенной (Полный доступ):**
   - Нажмите зеленую кнопку **`+ Создать новую вселенную`** в верхней панели (или на баннере режима чтения).
   - Выберите один из двух вариантов старта:
     - **С реальным ростером Автора (300 игроков с 02.01.2024)** — начните собственную ветку истории с 2 января 2024 года с каноничными 300 игроками и архивом 2023 года.
     - **Случайная генерация 300 новых игроков** — создайте полностью процедурную вселенную с нуля.
   - В своей вселенной вам доступны все функции: жеребьевка, ручной ввод счёта, пошаговая и полная симуляция турниров, ИИ-матчи и чекпоинты.

## ⚙️ Настройка ИИ-модуля (Groq API — опционально)

По умолчанию симулятор работает автономно на встроенном локальном движке.  
Если вы хотите генерировать развернутые ТВ-обзоры и пресс-конференции через LLM **Llama 3.3 70B (Groq)**:
1. Нажмите **`⚙️ Настройки API`** в верхней панели сайта.
2. Вставьте свой бесплатный ключ `gsk_...` с [console.groq.com](https://console.groq.com). Ключ сохраняется исключительно в `localStorage` вашего браузера.

## 💻 Локальный запуск

1. Установите зависимости:
   ```bash
   npm install
   ```
2. (Опционально) Создайте файл `.env.local` в корне проекта и укажите свой ключ Groq:
   ```env
   VITE_GROQ_API_KEY=gsk_ваш_ключ
   ```
3. Запустите dev-сервер:
   ```bash
   npm run dev
   ```
4. Запуск модульных тестов (19 тест-сьютов):
   ```bash
   node --test src/engines.test.js
   ```

⚙️ Настройки Groq API (Llama 3.3 / 3.1)

Сверхбыстрый Groq API используется для умной ИИ-симуляции матчей с цитатами игроков, ИИ-комментариев к введенному счету, послематчевых колонок финалов и генерации стилей игры молодых новичков.

По умолчанию предустановлен рабочий ключ Groq API. Вы можете заменить его на собственный в любой момент.
